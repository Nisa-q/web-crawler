# Web Crawler — Proje Belgeleri

Katana ile web sitelerindeki URL'leri tarama ve sonuçları yönetme uygulamasına ilişkin analiz belgeleri.

## Mevcut durum

Bu depoda şu anda README, .gitignore ve proje analizi bulunur. Analizde anlatılan uygulama kaynak kodları bu depoda yer almadığından, depo tek başına çalıştırılabilir bir uygulama değildir.

## İçerik

- [Proje analizi](PROJE_ANALIZI.md): mimari, veri akışı ve API açıklamaları.
- `.gitignore`: yerel dosyaları Git dışında tutma kuralları.

## Analizde anlatılan teknolojiler

Flask, SQLite, Next.js, React ve Katana. Bu liste analiz belgesine dayanır; çalışan uygulamanın doğrulandığı anlamına gelmez.

## Sonraki adımlar

1. Paylaşılacak kaynak kodları belirlemek.
2. Gerekli bağımlılık dosyalarını eklemek.
3. Kurulum ve çalıştırmayı doğrulayıp burada açıklamak.
4. Ekran görüntüsü ve kişisel katkı bölümünü eklemek.
